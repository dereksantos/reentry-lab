# Brand assets

| File | Use |
| --- | --- |
| `logo.svg` | The mark, for anything 48 px and up (README, docs, slides) |
| `logo-small.svg` | Small-size version for 16–48 px: thicker trail, larger capsule. Also served as `public/favicon.svg` |
| `logo-512.png` | Upload where an app logo is asked for, such as the GitHub OAuth app |
| `social-preview.png` | GitHub repo social preview (1280 × 640): Settings → General → Social preview |
| `../public/apple-touch-icon.png` | Home-screen icon (180 px, square; iOS rounds the corners) |

The mark is a capsule at the end of its glowing entry trail, heat shield leading and bow shock ahead, above the planet's limb.

The colors come from the app (`src/styles.css`):
- navy `#0b1e33`
- planet `#123a5e`
- atmosphere `#5ea2ff`
- plasma `#ff8a3d` through `#ff5a2a`
- shock `#ffd27a`
- capsule `#e4ebf3`

The wordmark is Barlow Condensed 600, upper case, with 0.04 em tracking.
