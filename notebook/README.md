# Research notebook

Everything here is plain files, so it works with git, your editor, and the research agent.

- `entries/` — research notes in Markdown, written by you (Save to notebook) or the agent.
- `runs/` — saved runs as JSON: the full parameter set plus a short summary. The app re-simulates from the parameters when you load or compare one.
- `chats/` — a readable log of every research conversation.
- `.context/` — working state the app shares with the agent (the run you have loaded, conversation threads). Safe to delete.
